# 🏃 3D Sphere Runner

A fast-paced 3D endless runner built with Three.js. Dodge obstacles, collect coins, chain combos up to 10x, and chase high scores!

## 🎮 Play
[**Play Live →**](https://TERA_USERNAME.github.io/3d-sphere-runner/)

## Controls
| Input | Action |
|-------|--------|
| `←` `→` / `A` `D` | Move left/right |
| `Space` / `W` / `↑` | Jump |
| Touch swipe | Mobile controls |

## Features
- 3 difficulty levels (Easy / Medium / Hard)
- Power-ups: 🛡️ Shield, 🧲 Magnet, 🦘 Double Jump
- 🪙 Coins + combo multiplier (up to 10x)
- 💥 Particle effects, screen shake, glowing trail
- 🔊 Procedural audio (jump, collision, music)
- 🏆 Leaderboard with localStorage

## Tech Stack
- Three.js (single HTML file, no build tools)
- Web Audio API for sounds
- Pure HTML/CSS/JS
